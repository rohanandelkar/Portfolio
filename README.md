# Rohan Andelkar - Portfolio

Personal portfolio for Rohan Andelkar, a Computer Science Engineering student working across machine learning, data products, cloud AI, and cybersecurity.

The site uses an editorial "lab notebook" visual direction to make projects, measurable outcomes, internships, and contact details easy to scan.

## Highlights

- Responsive portfolio layout with mobile navigation.
- Featured work across computer vision, security simulation, predictive modeling, and business intelligence.
- Project metrics including 69.1% mAP@50 for low-visibility object detection and approximately 94% accuracy for salary prediction.
- Experience timeline covering Microsoft Elevate, IBM SkillsBuild, CSRBOX, Edunet Foundation, and AICTE programs.
- Resume, GitHub, LinkedIn, email, and phone links.
- Static-friendly Next.js app suitable for Vercel deployment.

## Tech stack

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4
- Lucide React
- Google-hosted Inter font through `next/font`

## Run locally

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

The production build should complete successfully. The repository also contains legacy components from the previous portfolio version; lint warnings in those unused components may remain until they are removed or modernized.
